# Compétences spécialisées du projet

Réutiliser les skills Supabase/RLS, React et vérification Vercel lorsqu'ils sont disponibles dans l'outil de développement. Ces instructions sont des guides du dépôt, pas une installation de skills personnels ChatGPT.

- **Base et sécurité** : examiner schéma/politiques avant migration ; droits minimaux ; transaction de vérification ; tests propriétaire/tiers/visiteur ; ne pas résoudre une erreur en désactivant RLS.
- **Réservation** : convertir les durées pour le stockage ; valider côté serveur ; vérifier bornes, fuseaux, exclusions de chevauchement et transitions ; conserver l'historique.
- **React et interface** : état éditable des champs, labels accessibles, absence de succès avant confirmation serveur, chargement/erreur/reprise, séparation des composants et maîtrise des effets.
- **Notifications et PWA** : isolation par compte, compteur de non-lus, marquage/retour arrière, cache/version ; essai physique pour permissions et son, sans le confondre avec un test simulé.
- **Livraison** : commandes documentées, résultats observés, migration compatible, commit exact déployé READY et vérification du domaine public.
